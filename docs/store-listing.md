# Store listing

Copy for the Chrome Web Store and Firefox Add-ons (AMO) submissions. Keep every sentence free of medical claims.

## Name

Sukoon — Calm the Web

## Summary (132 characters max, Chrome)

Calms motion, flashing and hijacked scrolling on any website. Runs on your device only. Open source.

## Description

Sukoon calms the web for people whom motion hurts: vestibular disorders, photosensitivity, migraine, ADHD and autism.

- **Calm layer.** CSS animations and transitions finish instantly instead of playing; content that animates in is
  simply there.
- **Your reduced-motion setting, everywhere.** Many sites already ship a calm version behind "reduce motion" and
  never show it. Sukoon turns it on.
- **Scroll guard.** Smooth-scroll hijacking is bypassed so your device's own scrolling comes back; parallax layers
  stop moving.
- **Media guard.** Videos wait for you to press play; animated images stay on their first frame.
- **Panic freeze.** Alt+Shift+S covers the page with a still picture and stops everything underneath. Esc releases it.
- **Sensory Load Index.** See how much motion a page carries, as built and with Sukoon.
- **Flash Guard (Chrome).** On request, Sukoon watches the tab locally and dims moving content when flashing passes
  the WCAG 2.3.1 limits.

Everything runs on your device. Sukoon has no servers, no accounts, no analytics and no telemetry.

Sukoon is not a medical device. It reduces exposure to common motion and flash triggers and cannot guarantee
protection from seizures, migraines, dizziness or any other symptom.

Open source (MIT): https://github.com/AttSee/sukoon

## Single purpose (Chrome)

Reduce motion, flashing and hijacked scrolling on web pages for people who are sensitive to them.

## Permission justifications

| Permission | Justification |
| --- | --- |
| `storage` | Saves the user's settings and excluded sites on the device. |
| `scripting`, `<all_urls>` | Registers the calm stylesheet and scripts so they run before a page's first paint on every site; excluded sites are removed from the registration. |
| `activeTab` | Takes the still picture of the current tab for the panic freeze when the user presses the shortcut or the popup button. |
| `contextMenus` | "Freeze this page" and "Turn Sukoon off / on for this site" in the page's right-click menu. |
| `accessibilityFeatures.read` / `.modify` (Chrome) | The browser's own switch for animated images (GIF, APNG, WebP). |
| `tabCapture`, `offscreen` (Chrome) | Flash Guard, only when the user starts it: the tab's frames are analysed locally in an offscreen document and discarded. |
| `browserSettings` (Firefox) | The browser's own switch for animated images. |

Remote code: none. Data collection: none (Firefox `data_collection_permissions: none`).
